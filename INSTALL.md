# Installation

1. Open the `Muneebqasmi/Muneebqasmi` repository.
2. Replace the root `README.md` with the supplied README.
3. Upload the entire `assets/` folder to the repository root.
4. Commit to `main` and refresh the GitHub profile.

SVG graphics are self-contained and use no scripts or external fonts. The activity graph, streak widget, skill icons and badges load from third-party services and need an internet connection. If any remote image provider fails, remove or replace that image link.

Verify project wording and add repository links only after confirming their exact URLs. The phishing detection entry is intentionally marked unverified.
